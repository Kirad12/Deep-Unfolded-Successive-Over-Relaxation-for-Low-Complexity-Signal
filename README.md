# Deep-Unfolded-Successive-Over-Relaxation-for-Low-Complexity-Signal

PyTorch implementation of DU-SOR: a Deep Unfolded Successive Over-Relaxation network for low-complexity signal detection in large-scale optical MIMO (VLC/FSO) systems under IM/DD constraints. Achieves near-ML BER at O(L·K²) complexity vs O(K³) for MMSE/ZF.

This repository implements DU-SOR, a Deep Unfolded Successive Over-Relaxation network for signal detection in large-scale optical MIMO systems (indoor VLC and outdoor FSO links) under intensity-modulation/direct-detection (IM/DD) constraints. DU-SOR unfolds the classical SOR algorithm into a fixed-depth neural network, replacing its manually-tuned relaxation factor with a learned, layer-wise parameter trained end-to-end — closing the gap to near-optimal (ML-level) detection accuracy while keeping complexity at O(L·K²), versus O(K³) for MMSE/ZF and O(Mᴷ) for brute-force ML search. Includes full VLC/FSO channel simulation, classical baselines (ZF, MMSE, Gauss-Seidel, SOR), training/evaluation scripts, and complexity benchmarking — everything needed to reproduce the BER/BLER, convergence, and runtime results discussed in the accompanying thesis.
